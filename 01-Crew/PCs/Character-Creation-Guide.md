# Character Creation Guide

**The player guide now lives in one place — the wiki:** `The-Shadow-Exchange-Players/docs/Character-Creation-Guide.md` (on the player site: *Character Creation*).

*(This file used to duplicate it; the copies had drifted apart, so it is now a pointer. Edit the wiki version only.)*

**The short version:** read the Quick Start (5 min) → pick a playbook, name, look, heritage, background, **Vice + Purveyor** → 3 playbook dots + 4 more (max 2 per action; one for heritage, one for background, two free) → one special ability → Close Friend and Rival → Cursed Heirloom → one question for the GM → send it all to the GM before Session 0.
