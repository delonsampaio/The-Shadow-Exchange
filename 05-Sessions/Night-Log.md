# Night Log

**One line per sitting (a real evening).** At close-out the Co-GM asks the GM two questions (one at a time) and appends the line:
1. ❓ "Where did we stop: which beat?" (a natural stop, or out of evening)
2. ❓ "In one word: dragged, right, or rushed?"
3. ❓ "Is the session finished?" If not: ❓ "Resume at which beat?" (the Pause row is the single source for the next `continue session N`).

## How the Co-GM uses it
- **Nothing is cut (GM, 2026-11-21).** A session may take two or more nights; each prep lists its **safe stops**. This log shows how many nights each session really takes.
- **Sizing:** after 2–3 nights, size new preps in *beats per night* from this table (if a session takes two nights, write it as two halves with a built-in stop point between them).
- **Safe stop points:** note which beat each night ended on; never end a night on a Choice, a reveal or an Anchor decision.
- **Sitting vs session:** a *sitting* is a real evening at the table; a *session* is one prep file (a unit of story). **Every sitting** ends with a Night Log row. If a session ends mid-sitting, run its full close there, then continue. **Only a finished session** ends with Zoltar's card, the XP tally, the retrospective and the Faction Turn. A sitting that stops mid-session runs the **Pause** (`00-Canon/End-of-Session-Ritual.md` §0b). Downtime and the Entanglement follow a *score*, not the clock.
