# Wiki Soundtrack table (GM only)

The players' site has a **Soundtrack** page (GM decision 2026-11-24: public, small covers, first live after Session 0). After each real session, the tracks that actually played go on it, in the order they played, through `00-Canon/Wiki-Update-Protocol.md` step 3c and `docs/tools/wiki_soundtrack.py`.

Google's Gemini API terms (checked 2026-11-24): Google claims no ownership of generated content and has no ban on sharing it; we are responsible for how it is used. The page says the music is AI-made.

**Rules**
- Only tracks that actually played at a real session. Never a mock. Never a track from an unplayed session.
- A track is listed once, at the first session it played (the bookshop loop appears under Session 0 only).
- **Public titles are neutral**: no NPC secret, no reveal word, nothing about what the Subway is. Change a title here before publishing, never on the site only.
- **Track hold**: `listen` = a vocal track with generated words; the GM listens once and clears it (write `—`) before it goes up. `held` = stays off the page.
- **Cover hold**: `never` = the track goes up without its cover. `outcome` = check the cover still matches how the scene ended; if not, publish without it.
- Generic backup tracks are listed only if they were played; give them the session they first played in.
