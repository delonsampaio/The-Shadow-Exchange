# Running Gags & Forms Register

**Menace Rule:** gags live in the people, never in the monster on screen; never during an Anchor choice; never inside the Subway on the first visit (`Comedy-Playbook.md`, `CLAUDE.md`). Every spoken line is a **SAY** line read by the GM, not acted. **Source key:** CP = `Comedy-Playbook.md` · S0–S3 = `Session-0N-Prep.md` · S1P = `Season-1-Plan.md` · SC = `Score-Catalog.md` · C&C = `Curios-and-Chronicles.md` · LS = `Living-Subway.md`. **PROPOSAL** = invented here.
